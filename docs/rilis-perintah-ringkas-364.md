# Editor perintah ringkas — versi 364

- Satuan karung/kg berada di samping isian jumlah, pada ponsel dan desktop.
  Nama barang, merek, serta kemasan tetap lengkap; bilangan pecahan karung
  tetap ditolak. Tombol hapus tetap mudah disentuh.
- Pelanggan menjadi satu combobox. Ketikan memfilter pelanggan terdaftar;
  memilih hasil menetapkan ID pelanggan. Mengetik ulang menghapus pilihan
  lama agar nama yang sedang dicari tidak tersimpan dengan identitas lama.
  Pemilihan bisa melalui ketukan atau keyboard. Draf lama tetap dapat dibuka.
- Status simpan otomatis, penanganan jaringan, dan perbandingan konflik tetap
  tersedia. Tidak ada perubahan skema, aturan stok, atau verifikasi timbang.

Uji lokal: 78 uji browser/kontras dan 87 pemeriksaan pendukung lulus. Setelah
perapian akhir, 6 kombinasi editor (320/390/1440 px, terang/gelap) lulus;
pemilihan keyboard diperiksa ulang dan lulus. Penjaga sinkronisasi 4 lulus.
Data operasional tidak dipakai untuk pengisian/penerbitan contoh.
