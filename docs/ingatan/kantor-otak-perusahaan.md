Kantor AI bot has TWO memory layers (part of [[kantor-ai-project]], distinct from [[agentic-layer]]):

1. **Ingatan percakapan (short-term):** `app/kantor/riwayat.py` (`KantorChatRiwayat`). Only last **8 rows/messages** loaded to model context (`BATAS_GILIRAN=8`), each capped 800 chars, keeps last 40 rows/user (older pruned). Kept small deliberately to cut token/credit cost. `/lupakan` clears it.

2. **Otak perusahaan (permanent, unlimited):** `app/kantor/pengetahuan.py` → `knowledge/` (`SopDokumen`/`SopChunk`; ingest + retrieve). `cari_pengetahuan` / `simpan_pengetahuan` tools. NOT gated (internal/reversible), unlike external Drive/email/calendar actions.

**Semantic search LIVE (2026-08-09) via Voyage AI:** `app/kantor/knowledge/embed.py` calls Voyage (`https://api.voyageai.com/v1/embeddings`, model `voyage-3.5-lite`, 1024-dim) over HTTP stdlib — no heavy dep. Env `VOYAGE_API_KEY` set on the `penggilingan-beras` Railway service (NOT `mcp`). Voyage is only an embedding provider — NOT an agent, nothing like Hermes. On `simpan`, chunks are embedded → stored as JSON in `SopChunk.embedding`; on `cari`, query embedded → cosine top-k, threshold `_AMBANG=0.40` (verified: senada ~0.49 vs beda topik ~0.33). Keyword (`retrieve.cari`) is the safety-net fallback if Voyage missing/fails, so it never errors.

**Proactive auto-save (2026-08-09):** agent system prompt now tells it to save durable facts UNPROMPTED (rapat decisions, policies, PIC/kontak pemasok & klien, key numbers/targets, org/jabatan, owner's standing preferences) and reply briefly ('📝 kucatat: …'); must NOT save trivia/one-off/daily-changing data (stok/saldo/agenda) or raw credentials (password/PIN/token/API key); `cari_pengetahuan` first to avoid duplicates.

**Role-gated sensitivity (2026-08-10):** knowledge `ranah` field now doubles as a sensitivity lock — `ranah="rahasia"` = admin-only; `role` is threaded from `run_kantor_agent` → `pengetahuan.jalankan(..., role=role)` → `cari(query, role=...)`; non-admin gets `larang={"rahasia"}` which excludes rahasia docs in BOTH semantic (`SopDokumen.ranah.notin_`) and keyword (`retrieve.cari(tanpa_ranah=...)`) paths. `simpan_pengetahuan` gained a `rahasia` bool; agent prompt: sensitive reference data (IT Accounts/perbankan/akses/PII) → save with rahasia=true, but NEVER store raw credentials. Bot kantor is open to role in {admin, staff} (currently only 1 admin user), so this gating matters before staff are added. Verified: sensitive queries → admin sees "IT Accounts —*", staff does not.
