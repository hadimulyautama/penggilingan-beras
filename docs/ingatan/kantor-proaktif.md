Kantor AI is moving from reactive (answers when asked) to **proactive** (surfaces things unprompted) — the owner's chosen frontier for making the agent feel "handal" (part of [[kantor-ai-project]]). Background pollers live in `app/services/*_poller.py`, each registered as an asyncio task in `app/main.py` lifespan, sending to `settings.admin_telegram_id` via the `kantor` bot. Timezone WIB = UTC+7 computed manually (no tzdata dependency).

**LIVE (2026-08-10):**
- **Email notifier** — `app/services/email_notif_poller.py`. **Every 30 min, 24/7** (quiet hours removed 2026-08-11 per owner). Summarizes new inbox mail across the 3 managed mailboxes ([[kantor-email-gmail]]); dedupe via Gmail label `AI-Notif` (state in Gmail, survives restart). One Telegram message per cycle. In `main.py`, the rapi task is created BEFORE the notif task so auto-tidy archives routine mail first each cycle → notifier only pings what's left. (True real-time via Gmail watch+Pub/Sub was declined — needs GCP billing; 30-min polling chosen as free near-real-time.)
- **Briefing pagi** — `app/services/briefing_poller.py`. 07:00 WIB, **Mon–Sat** (Sunday off), once/day (in-memory `terkirim` date dedupe, fires within 07:00–08:59 window). Three sections: (1) email semalam (`mail_gmail.daftar`, newer_than:15h), (2) agenda & jatuh tempo (`operasi.lihat_agenda` today..+7d — owner enters renewals as CALENDAR events, e.g. domain renewal 11 Aug, Kledo 14 Aug, so due-dates surface here without a new store), (3) ringkasan operasional (`services.dashboard.dashboard_data` → gabah/pengeringan/silo/giling/stok PK). Owner did NOT include pending approvals/HR in the brief (easy to add later). Each section try/except-guarded.

Also LIVE (2026-08-10):
- **Radar jatuh tempo (Fase 2)** — `app/services/deadline_poller.py`. Daily 07:00 WIB, alerts at H-7/H-3/H-1/H-0 (+overdue ≤3d), silent otherwise. Sources: primary Calendar events tagged 🔔/keyword (renewal/tempo/pajak/bayar/kontrak…) + IT Accounts Services "Tgl Renewal" col (Indonesian date parse). Calendar wins per-date dedup.
- **Pemindai tagihan (Fase 2b)** — `app/services/billing_poller.py` + `app/kantor/billing.py`. Every 3h (06:00–22:00 WIB), scans managed mailboxes for billing/reminder emails (keyword prefilter → Haiku extracts {vendor, jatuh_tempo, jumlah}, rejects promos/notifs), then PROPOSES a `kalender_buat` reminder via the human gate (owner ✅ → 🔔 event → flows into the radar). Gmail label `AI-Tagihan-Dicek` dedupes. Conservative: no date/low-confidence → not proposed. Also made `persetujuan_poller` approval text generic (was Drive-only wording).

- **UNIFIED email poller (2026-08-11)** — `app/services/email_rapi_poller.py` now does classify→act→notify in ONE pass (the separate `email_notif_poller` was REMOVED from `main.py` to kill the race where routine mail got pinged before tidy ran). Per new inbox email (Haiku via `rapi.proses`): 'rutin' → auto-archive SILENT (no ping); 'penting' → collected & reported in one Telegram msg; 'ragu' → gate proposal. 'rutin' now explicitly includes automated bank/e-wallet notifications (BRI/BCA/Mandiri: transaksi/mutasi/e-statement/receipt) AND GajiHub daily presensi/activity reports; still 'penting': unpaid bills w/ due date, mail from people, GajiHub approval-needed (lembur), and OTP/login/security (never touched). Ragu proposals (jenis `email_arsip`) show custom buttons **🗑️ Tidak penting** (=kaksi:ok → archive) / **📌 Penting** (=kaksi:no → leave) via jenis-aware `persetujuan_poller._keyboard`.
- **Auto-rapi inbox** — `app/services/email_rapi_poller.py` + `app/kantor/rapi.py`. Every 2h (06:00–22:00 WIB), Haiku classifies new inbox emails per managed mailbox → 'rutin' (promos/newsletters/bank-transaction-notifs/OTP) AUTO-ARCHIVED (reversible: remove INBOX + labels Auto-Rapi & AI-Notif; no permanent delete) · 'penting' left alone · 'ragu' → proposes archive via the human gate (jenis `email_arsip` in `persetujuan._lakukan` → `mail_gmail.arsipkan`). Conservative: any doubt → 'ragu' (ask), never auto-archive something possibly important. Owner's spec: "rapikan email rutin tidak penting otomatis, kalau ragu tanya dulu." Gmail label `AI-Rapi-Cek` dedupes. Verified: KlikBCA notifs → 'rutin'.
