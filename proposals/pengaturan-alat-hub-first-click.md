## Actual native scope

`pengaturan.halaman_alat` still depends on native `butuh_super` in its original position. Its bare Alat branch now negotiates an early read shape after that dependency. `/pengaturan/silo`, all queries/feedback, POSTs and `X-Pindah:1` stay native; inherited X-Kerangka cannot turn X-Pindah data into a shell. `_halaman_alat`, stock/silo/machine readers, every writer, operation keys/replay, existing configuration, permissions and recovery policy remain byte/AST-equivalent outside this GET wrapper.

The native `hmu_tampilan/templates/alat.html` is **a three-link hub**, not an editor: Pengaturan alat; its existing grouping explanation; **Mesin & line produksi**, **Silo**, **Sebab berhenti proses**. The early layout has the same exact link labels/order/addresses. It has no configured data, record, fields, fake count/empty message, active flag, save or form. GET navigation links remain usable while the same-URL native access check runs; each destination retains its own native guard.

`guard_native` requires GET, same actual request-state account, no portal and forced-password false, then calls the **actual native `butuh_super(akun)`**. It does not derive eligibility from `is_admin`, the master-pair flag or a new role list. Native denial yields no optional shape metadata. The existing narrow recovery condition remains owned by native security: `is_super` OR `is_admin and pemulihan_lama_diizinkan()`, where the latter requires no company and no active Super. No recovery operation or new grant is exposed.

There is a cost boundary: direct-document shell still executes its original dependency and the family reassertion; a legacy recovery Admin may incur a repeated native recovery-predicate DB read. Normal Super short-circuits that predicate. Native context/navigation construction is still present. The background `X-Pindah:1` GET continues through original `_halaman_alat`, including its currently unused machine/silo/stock composition before the hub render; it was **not optimized or moved** in this scope. No zero-query or latency claim follows from pure source checks. Root can measure these costs during sequential runtime work.

`window.PadiKerangkaPengaturanAlatUI.buat(target, baseHTML, context, CAP, sessionToken)`

The factory accepts only `/pengaturan/alat`, returns null or `{versi:1,alamat,konteks,cap,html}`, and does not infer authority from the URL. It checks exact private targets/schema/source/CAP/context/session, a connected unique host, unique current and detached native frame/main/session with containment, exact current source address and bound markers. Wrong/old/missing metadata, master Admin metadata, other paths/query/action URLs, portal/editor source, malformed/oversize base and invalid hub shape decline. Only the exact three native links are permitted in the public variant. No POST, storage, account/stock lookup or configuration action is performed.
